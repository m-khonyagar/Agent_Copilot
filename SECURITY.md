# Security Policy

## Supported scope
Security reports are relevant for active product code in `taskflow/`.

## Reporting
Please do not open public issues for vulnerabilities.
Report security concerns privately through GitHub security reporting or by contacting the repository owner directly.

## Expectations
- Never commit secrets, `.env` files, tokens, or production credentials.
- Treat sandboxed code execution and agent tool permissions as high-risk surfaces.
- Document any security-sensitive behavior changes in pull requests.
